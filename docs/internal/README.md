# Internal working artifacts

- **Audience:** maintainers and agents working on the repo itself
- **Deployment target:** read-only; ephemeral
- **Authority:** working planning artifacts — not user-facing docs, not a spec
- **Edit rule:** in-flight plans/specs live here; promote anything durable into `docs/` or `docs/spec/`

Holds development planning material (e.g. `superpowers/` plans and specs) that supports work
on the workbench but is not part of the operator documentation set. The `superpowers/`
subtree is git-ignored (local-only); this README is the tracked marker for the area.
